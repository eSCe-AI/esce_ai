[1. INFORMASI PROYEK & VISI STRATEGIS]

Nama Produk            : eSCe AI
Ticker Token           : $ESCE (Token utilitas ekosistem)
Nama Domain & Folder   : esceai (huruf kecil semua)
Ekosistem Utama        : Solana (Solana-First Approach)
Visi Utama             : Membangun platform kecerdasan buatan (AI Agent) berbasis
                         Solana yang bertindak sebagai mitra analitis, evaluator
                         psikologi trading, dan pengelola risiko, serta didukung
                         oleh utilitas token $ESCE untuk eksekusi perdagangan
                         otonom (autonomous execution).

PENDEKATAN BERBASIS MILESTONE (SOLANA-FIRST APPROACH):

Tahap 1 (MVP & Web3 Identity):
Integrasi dompet Solana (@solana/wallet-adapter) untuk otentikasi, pembacaan
riwayat transaksi on-chain, agen AI untuk diskusi pengambilan keputusan berdasarkan
riwayat trading dan pengenalan utilitas token $ESCE bagi investor dan early adopter.

Tahap 2 (Smart Analytics & Ecosystem Integration):
Pemindaian sentimen pasar Solana secara real-time, integrasi data
portofolio mendalam, dan mekanisme utilitas $ESCE (seperti staking atau pembukaan
fitur AI tingkat lanjut).

Tahap 3 (Autonomous Agent & DEX Execution):
Agen AI otonom yang mengeksekusi perdagangan kecepatan tinggi di protokol DEX
Solana (seperti Jupiter Aggregator atau Raydium) dengan pengaman risiko
(Risk Guard) berbasis smart contract.

--------------------------------------------------------------------------------

[2. RINCIAN FITUR BERDASARKAN TAHAPAN]

A. TAHAP 1: MVP, ON-CHAIN IDENTITY & TOKEN UTILITY ($ESCE)
   * Solana Wallet Connection: Masuk/Login menggunakan dompet Solana (Phantom/
     Solflare) sebagai identitas utama pengguna (Sign-In with Solana).
   * On-Chain Data Parsing & Analytics: Membaca riwayat transaksi dompet atau
     data yang diunggah untuk menghitung metrik statistik presisi (Win Rate,
     Risk-to-Reward Ratio, Maximum Drawdown).
   * Deteksi Pola Emosi & Perilaku: Mengidentifikasi kebiasaan buruk trader
     (overtrading, revenge trading, melanggar stop-loss).
   * $ESCE Token Utility Integration: Memperkenalkan token $ESCE sebagai kunci
     akses (token-gated access) untuk fitur analisis AI lanjutan (penting untuk
     pitching investor).
   * Conversational AI Partner: Antarmuka obrolan interaktif berkarakter mentor
     manajemen risiko yang objektif.

B. TAHAP 2: MARKET SENTIMENT & ECOSYSTEM EXPANSION
   * Market Narrative & Sentiment Scanner: Memindai tren, sentimen, dan
     volatilitas ekosistem Solana secara eksternal.
   * Contextual Risk Advice: Menggabungkan analisis psikologi pengguna dengan
     kondisi pasar real-time untuk memberikan rekomendasi position sizing akurat.
   * Tokenomics & Governance: Memperluas utilitas $ESCE untuk tata kelola
     komunitas atau program insentif kedisiplinan trading.

C. TAHAP 3: EKSEKUSI OTONOM (AUTONOMOUS TRADING)
   * Automated DEX Execution: Integrasi penuh dengan likuiditas Solana (Jupiter
     Swap API) untuk eksekusi order otomatis.
   * Smart Contract Risk Guard: Protokol pengaman otomatis berbasis smart contract
     (Anchor Framework) untuk memastikan batasan risiko harian pengguna tidak
     dilanggar oleh AI.

[3. TECH STACK & ARSITEKTUR SISTEM (esceai)]

Struktur Direktori Folder:

/esceai
├── /frontend      (Next.js / React.js dengan Tailwind CSS & Shadcn UI)
├── /backend       (Python / FastAPI / Pandas untuk kalkulasi statistik presisi)
└── /contracts     (Solana / Anchor untuk Risk Guard & Token Smart Contract)

Komponen Teknologi:
- Frontend & Web3 Layer : Next.js, @solana/wallet-adapter, @solana/web3.js, Tailwind CSS
- Backend Engine        : Python FastAPI, Pandas/NumPy (Anti-halusinasi angka)
- AI Core (LLM API)     : OpenAI API / Claude API (System Prompt Mentor Keuangan)
- Blockchain Layer      : Solana Devnet/Mainnet, Anchor Framework, Jupiter Swap API
